# kirana-ledger (POV)

Voice-first udhaar (credit) ledger for small Indian shopkeepers, backed by a knowledge graph.

> Work in progress. See `PLAN.md` for the architecture and build order and `CHANGELOG.md` for progress.

```bash
make setup   # one-time: venv + pip + npm install
make test
make demo    # http://localhost:8141/app/
```
